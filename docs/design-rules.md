# デザインルール

## 1. キャンバスサイズと描画可能領域

デバイスの種別（液晶キーまたはダイヤル液晶）に応じて、解像度とパディングが定数として厳密に定義されています。表示崩れを防ぐため、すべてのSVG描画はこの定数を基準とした動的な座標計算に基づいて行われなければなりません。

### 1.1 デバイス仕様

| デバイス種別             | 解像度（幅 × 高さ） | viewBox 基準値 | パディング（四辺） | 描画可能座標範囲（X） | 描画可能座標範囲（Y） |
| :----------------------- | :------------------ | :------------- | :----------------- | :-------------------- | :-------------------- |
| **Keypad（液晶キー）**   | 144 × 144 px        | `0 0 144 144`  | 10 px              | `10` ～ `134`         | `10` ～ `134`         |
| **Dial（ダイヤル液晶）** | 200 × 100 px        | `0 0 200 100`  | 8 px               | `8` ～ `192`          | `8` ～ `92`           |

> [!IMPORTANT]
>
> - ダイヤル液晶（Dial）の描画可能領域は、キャンバスサイズ（200 × 100 px）に対して左右に 8 px、上下に 8 px のパディングを確保します。
> - 液晶キー（Keypad）の描画可能領域は、キャンバスサイズ（144 × 144 px）に対して四辺に 10 px のパディングを確保します。

## 2. レイアウトの動的調整ルール

### 2.1 タイトル表示時の調整（Show Title）

プロパティインスペクタ（設定画面）におけるタイトルの表示・非表示切り替えに応じて、SVG内のコンテンツ座標を動的に調整します。

- **タイトル表示ありの場合**:
  - 画面上部（Y = 16 付近）にタイトルテキスト（フォントサイズ 14, 色 `#8f8f8f`）を配置します。
  - タイトルが描画領域を占有するため、メインコンテンツの描画位置を下方へオフセット（`CENTER_OFFSET_Y = 10`）し、コンテンツ自体の高さや円の半径を縮小してはみ出しを防止します。
- **タイトル表示なしの場合**:
  - コンテンツを画面中央にアライメント調整し、表示領域を最大限に活用して視認性を高めます。

## 3. カラーパレット定義

プラグイン全体の視認性と一貫性を担保するため、色は `Color` 定数（`src/utils/image.ts`）で定義されたカラーパレットのみを使用します。

| カラー名          | カラーコード | 用途・セマンティクス                                 | 設計上の意図                                          |
| :---------------- | :----------- | :--------------------------------------------------- | :---------------------------------------------------- |
| `Color.BLACK`     | `#111111`    | 背景色、ベース枠の塗りつぶし                         | 液晶のコントラストを最適化し、黒浮きを防ぐ            |
| `Color.DARK_GREY` | `#2e2e2e`    | ガイドライン、未達成バー、非アクティブ枠、タイヤ背景 | 背景とコンテンツを視覚的に分離する境界線              |
| `Color.GREY`      | `#8f8f8f`    | 単位ラベル、タイトル、項目名、説明テキスト           | 主情報を邪魔しない補助情報用のカラー                  |
| `Color.WHITE`     | `#dedede`    | デジタル速度、現在値テキスト、アクティブテキスト     | 純白（`#ffffff`）を避けることで実機での眩しさを抑える |
| `Color.GREEN`     | `#00e567`    | ギア枠、適正動作範囲、正常状態                       | 高い視認性と直感的な「正常・適正」を表現              |
| `Color.YELLOW`    | `#c7c600`    | ピーク値、警告状態、高回転（シフトアップ準備）       | 注意を促すためのセカンダリカラー                      |
| `Color.RED`       | `#ff5846`    | 現在のGボール、過熱状態、レッドゾーン（限界値）      | 最も注意すべき重要情報・警告を表す                    |

## 4. 動的グラデーションとパフォーマンス設計

連続して変化する数値（サスペンション移動量やタイヤ温度など）を表現する場合、色相の急激な変化によるチラつきを防ぐため、滑らかなカラーグラデーションを採用します。

### 4.1 HSL色空間からRGBへの連続変換

- `hslToRGB(hue, 100, 50)` 変換関数を使用し、数値に応じた色相（青:240° ～ 緑:120° ～ 赤:0°）のRGBカラーを算出します。
- **タイヤ温度（C）の変化ルール**:
  - `40℃` 未満: 水色 ～ 青
  - `40℃` ～ `80℃`: 青（240°）から緑（120°）へのグラデーション（冷えている状態）
  - `80℃` ～ `100℃`: 緑（120°）固定（適正動作温度）
  - `100℃` ～ `120℃`: 緑（120°）から赤（0°）へのグラデーション（過熱警告状態）
  - `120℃` 超: 赤（0°）固定

- **サスペンション移動量（%）の変化ルール**:
  - `0%` ～ `40%`: 青（240°）から緑（120°）へのグラデーション（最大伸長付近）
  - `40%` ～ `60%`: 緑（120°）固定（適正範囲）
  - `60%` ～ `100%`: 緑（120°）から赤（0°）へのグラデーション（最大圧縮付近）

### 4.2 即時実行関数（IIFE）による事前計算（キャッシュ）

毎フレームのUDP受信時（最大20FPS）にカラー変換計算を行うのはCPUの負担になるため、あらかじめ取りうる値に対応するカラーコードを配列にキャッシュします。

- タイヤ温度用キャッシュ: `TIRE_COLORS`（40℃ ～ 120℃ の範囲を事前に計算）
- サスペンション用キャッシュ: `SUSPENSION_TRAVEL_COLORS`（0% ～ 100% の範囲を事前に計算）
- 描画時は、丸めた数値をインデックスとして配列から `O(1)` の定数時間で色を取得し、描画パフォーマンスを極大化します。

## 5. タイポグラフィ

- **フォントファミリー**：
  - グローバルフォント設定に基づき、動的にSVGのスタイルシートへ埋め込まれます。
  - 標準のデフォルト設定は「指定なし（空欄）」であり、この場合は Stream Deck 描画システムの標準フォントが適用されます。特定のフォント（例：`BIZ UDGothic` 等）がインストールされている環境では、Property Inspector（設定画面）のフォント選択リストから明示的に選択して適用します。
  - Stream Deck の描画制限により `font-family` の複数指定（カンマ区切りによるフォールバック）は動作しません。
- **フォントスタイル**:
  - 基本的にすべてのテキスト要素に対して `<style>text { font-family: ...; font-weight: bold; }</style>` を適用し、高精細液晶ディスプレイにおける視認性とフォントの太さを維持します（SVGインラインでの個別の `font-weight="800"` 指定は廃止）。

## 6. 操作割り当ての一貫性

ユーザー操作（短押し、長押し、ダイヤル回転）に対する挙動は、すべてのアクションで以下の基準に従って設計されなければなりません。

1. **短押し（液晶キー押下 / ダイヤルプッシュ / 液晶タップ）**:
   - 表示単位（KM/H <-> MPH、℃ <-> ℉）や、表示モード（%表示 <-> 実数表示）などの「主要設定値」のトグルまたはループ切り替えに割り当てます。
2. **ダイヤル回転（Dial Rotate）**:
   - 表示対象（車輪位置：All -> FL -> FR -> RL -> RR）や、表示スケール（Gフォースの上限：1.0G ～ 3.0G）の「順次切り替え（増減）」に割り当てます。
3. **長押し（500ms判定）**:
   - ピークGのリセットなど、一時的な内部状態のクリアを伴う破壊的操作に割り当てます。
