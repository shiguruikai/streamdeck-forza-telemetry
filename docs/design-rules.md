# UIデザインルール

## 1. キャンバスサイズと描画領域

デバイスの種別に応じて、解像度とパディングを定義している。すべてのSVG描画は、この定数を基準とした動的な座標計算に基づいて行う必要がある。

| デバイス種別             | 解像度（幅 × 高さ） | viewBox 基準値 | パディング（四辺） |
| :----------------------- | :------------------ | :------------- | :----------------- |
| **Keypad（液晶キー）**   | 144 × 144 px        | `0 0 144 144`  | 10 px              |
| **Dial（ダイヤル液晶）** | 200 × 100 px        | `0 0 200 100`  | 8 px               |

## 2. レイアウトの動的調整ルール

### 2.1 タイトル表示時の調整（Show Title）

プロパティインスペクタの設定（Show Title）に応じて、コンテンツ座標を動的に調整すること。

- **タイトルあり**: 画面上部にタイトルテキスト（Y = 16付近、フォントサイズ14、色 `Color.GREY`）を表示。メインコンテンツは下方へオフセット（`CENTER_OFFSET_Y = 10`）し、コンテンツのサイズや半径を縮小してはみ出しを防ぐ。
- **タイトルなし**: コンテンツを画面中央にアライメントし、表示領域を最大化する。

## 3. カラーパレット定義

色のハードコーディングを禁止し、[image.ts](../src/utils/image.ts) で定義された `Color` 定数を必ず使用すること。

- `Color.WHITE`: デジタル速度、現在値、アクティブテキスト用。まぶしさ低減のため純白は避ける。
- `Color.GREY`: 単位ラベル、タイトル、補助テキスト用
- `Color.DARK_GREY`: ガイドライン、非アクティブ枠、タイヤ・バー背景
- `Color.BLACK`: 背景色、ベース枠。液晶の黒浮き防止用
- `Color.RED`: 現在のGボール、過熱状態、レッドゾーン（限界値）
- `Color.YELLOW`: ピーク値、警告状態、高回転（シフトアップ準備）
- `Color.GREEN`: ギア枠、適正動作範囲、正常状態

## 4. 動的グラデーションの変換ルール

数値に応じて色相（青:240° ～ 緑:120° ～ 赤:0°）を動的変化させる際、以下の仕様を順守すること。

- **タイヤ温度（℃）**:
  - 40℃未満: 青（240°）
  - 40℃ ～ 80℃: 青（240°）から緑（120°）へのグラデーション（冷えている状態）
  - 80℃ ～ 100℃: 緑（120°）固定（適正動作温度）
  - 100℃ ～ 120℃: 緑（120°）から赤（0°）へのグラデーション（過熱警告）
  - 120℃超: 赤（0°）固定
- **サスペンション移動量（%）**:
  - 0% ～ 40%: 青（240°）から緑（120°）へのグラデーション（最大伸長付近）
  - 40% ～ 60%: 緑（120°）固定（適正範囲）
  - 60% ～ 100%: 緑（120°）から赤（0°）へのグラデーション（最大圧縮付近）

## 5. タイポグラフィ

- **フォント適用**: [image.ts](../src/utils/image.ts) の `getCommonStyle()` を通じて、SVGのスタイルシートへ一括適用すること。
- **スタイル制約**: テキストのフォントウェイトはボールド（`font-weight: bold`）で統一し、個別要素でのウェイト指定は行わない。複数フォント（カンマ区切りによるフォールバック）指定は動作しないため禁止する。

## 6. 操作割り当ての一貫性

ユーザー操作に対する挙動は全アクションで以下に統一すること。
なお、ダイヤルのタッチパネル操作は実装しない。

1. **短押し（液晶キー押下、ダイヤルプッシュ）**:
   - 主要設定値（KM/H <-> MPH、℃ <-> ℉、%表示 <-> 実数表示など）のトグル切り替え。
2. **ダイヤル回転**:
   - 表示対象（車輪位置など）や表示スケール（Gフォース上限など）の順次切り替え。
3. **長押し**:
   - ピーク値のリセットなど、状態を変更する破壊的な操作。
