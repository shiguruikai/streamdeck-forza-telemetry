# UIデザインルール

## 1. キャンバスサイズと描画領域

デバイスの種別に応じて、解像度とパディングを定義している。すべてのSVG描画は、この定数を基準とした動的な座標計算に基づいて行う必要がある。

| デバイス種別             | 解像度（幅 × 高さ） | viewBox       |
| :----------------------- | :------------------ | :------------ |
| **Keypad（液晶キー）**   | 144 × 144 px        | `0 0 144 144` |
| **Dial（ダイヤル液晶）** | 200 × 100 px        | `0 0 200 100` |

## 2. レイアウトの動的調整ルール

### 2.1 タイトル表示

- **液晶キーの場合**:
  - タイトルは Stream Deck アプリ側の標準機能（色や表示位置のカスタマイズが可能）で描画する。
  - タイトル表示位置（上または下）に応じて、コンテンツが重ならないようY軸にオフセットを適用して位置を調整する。
- **ダイヤル液晶の場合**:
  - タイトルは Stream Deck アプリで入力されたタイトルテキストと色に応じて、プラグイン側で描画する。
  - タイトルの表示位置は左上に限定し、必要に応じてコンテンツの位置やサイズを調整する。

## 3. カラーパレット定義

色のハードコーディングを禁止し、[common.ts](../src/utils/graphics/common.ts) で定義された `Color` 定数を必ず使用すること。

- `Color.WHITE`: デジタル速度、現在値、アクティブテキスト用。まぶしさ低減のため純白は避ける。
- `Color.GREY`: 単位ラベル、タイトル、補助テキスト用
- `Color.DARK_GREY`: ガイドライン、非アクティブ枠、タイヤ・バー背景
- `Color.BLACK`: 背景色、ベース枠。液晶の黒浮き防止用
- `Color.RED`: 現在のGボール、過熱状態、レッドゾーン
- `Color.YELLOW`: ピーク値、警告状態、レッドゾーン手前
- `Color.GREEN`: ギア枠、適正動作範囲、正常状態

## 4. 動的グラデーションの変換ルール

数値に応じて色相（青:240° ～ 緑:120° ～ 赤:0°）を動的変化させる際、以下の仕様を順守すること（彩度100%、輝度55%）。

- **タイヤ温度（℃）**:
  - 40℃未満: 青（240°）
  - 40℃ ～ 80℃: 青（240°）から緑（120°）へのグラデーション（冷えている状態）
  - 80℃ ～ 100℃: 緑（120°）固定（適正動作温度）
  - 100℃ ～ 120℃: 緑（120°）から赤（0°）へのグラデーション（過熱警告）
  - 120℃超: 赤（0°）固定
- **サスペンション移動量（%）**:
  - 0% ～ 40%: 青（240°）から緑（120°）へのグラデーション（最大伸長付近）
  - 40% ～ 60%: 緑（120°）固定（適正範囲）
  - 60% ～ 100%: 緑（120°）から赤（0°）へのグラデーション（最大圧縮付近）

## 5. タイポグラフィ

- **フォント適用**: [common.ts](../src/utils/graphics/common.ts) の `getCommonStyle()` を通じて、SVGのスタイルシートへ一括適用すること。
- **スタイル制約**: テキストのフォントウェイトはボールド（`font-weight: bold`）で統一し、個別要素でのウェイト指定は行わない。複数フォント（カンマ区切りによるフォールバック）指定は動作しないため禁止する。

## 6. ギア表示の共通デザイン仕様

すべてのギア表示において、文字と外円のアスペクト比率と線の太さを一定に保つため、共通の描画関数 **[generateGearSvgComponent](../src/utils/graphics/common.ts)** を使用します。

## 7. 操作割り当ての一貫性

ユーザー操作に対する挙動は全アクションで以下に統一すること。ただし、対象となる設定値や状態が存在しないアクションにおいては、該当する操作を無効（何もしない）とする。
なお、ダイヤルのタッチパネル操作は実装しない。

1. **短押し（液晶キー押下、ダイヤルプッシュ）**:
   - 主要設定値（KM/H ⇔ MPH、℃ ⇔ ℉、%表示 ⇔ 実数表示など）のトグル切り替え。（対象設定がないアクションは無効）
2. **ダイヤル回転**:
   - 表示対象（車輪位置など）や表示スケール（Gフォース上限など）の順次切り替え。
3. **長押し**:
   - ピーク値（Gフォースの最大値など）のリセットなど、状態を変更する破壊的な操作。（リセット対象データがない、またはゲーム側が状態を管理しているアクションは無効）

## 8. アイコン

- **拡張子指定**: `manifest.json` 内では、自動拡張子解決（@2x対応等）のため画像パスの拡張子は省略する。
- **プラグイン用アイコン**: 256×256 px および 512×512 px (@2x)、PNG形式。
- **カテゴリ用アイコン**: 28×28 px および 56×56 px (@2x) のPNG、またはSVG形式。白色（`#FFFFFF`）単色、背景透過。
- **アクションアイコンとキーアイコン**:
  - アクションリスト用の `icon.svg` と液晶キー用の `key.svg` は同一のファイルとする。
  - 解像度は `144×144 px`（`viewBox="0 0 144 144"`）とする。
  - 白色（`#FFFFFF`）単色、背景透過。
  - 縮小表示（20×20 px）に耐えうる視認性を確保するため、線は太め（`stroke-width="4"` 以上）に設計し、つぶれやすい細部や小さな文字は避けること。
