# Elgato Marketplace無料公開に向けたロードマップ

## 概要

本プラグインをElgato Marketplaceへ無料公開するためのロードマップです。Elgatoが提示するPlugin Guidelinesに準拠し、スムーズな審査通過を目指します。

## マイルストーン

1. **フェーズ1：ガイドライン準拠と品質検証**
2. **フェーズ2：掲載用メディア・ドキュメント作成**
3. **フェーズ3：リリースビルドと検証**
4. **フェーズ4：Maker Consoleでの申請と審査対応**

---

## 各フェーズの詳細タスク

### フェーズ1：ガイドライン準拠と品質検証

公式のガイドラインに従い、以下を検証すること。

#### 1. ソースコード・構成ファイルの検証（静的チェック）

- [x] **UUIDの検証**
  - `manifest.json` のプラグインUUIDが、Maker Consoleに登録する組織名（Maker Name）およびプロダクト名と一致していることを確認する。
- [x] **アセット画像の規格・解像度の確認**
  - 各アセットが [design-rules.md](design-rules.md) で定義された規格および解像度を満たしていることを確認する。
- [x] **タッチストリップレイアウト（Layouts）の境界検証**
  - すべてのUI要素が 200x100 px のレイアウト境界内に収まっていることを設定ファイル（`layouts/*.json`）等から確認する。
- [x] **Property Inspector（設定画面）の品質検証**
  - 画面内に「寄付（Donation）やスポンサーのリンク」「著作権（Copyright）表示」が含まれていないことをソースコードから確認する。
  - 設定保存用の「保存」ボタンが存在せず、自動保存機能が実装されていることをソースコードから確認する。

#### 2. 実機およびシミュレータでの動作確認（動的検証）

- [ ] **機能と操作性の一貫性の確認**
  - 全てのアクションにおける以下の操作仕様を実機またはシミュレータで検証する。
    - **短押し（液晶キー押下、ダイヤルプッシュ）**: 表示単位などのトグル切り替えが正常に機能するか。
    - **ダイヤル回転**: 表示スケールや車輪位置の順次切り替えが正常に機能するか。
    - **長押し**: ピーク値が正常にリセットされるか。
- [ ] **エラーおよびフィードバック処理の動作検証**
  - テレメトリの受信不可、ポート重複などのエラー時に `showAlert` がトリガーされ、適切にログ出力されるか。
  - 成功時に不要な `showOk` が表示されないか（UI上の状態遷移でわかる場合は非表示に）。
- [ ] **Property Inspector（設定画面）の動作検証**
  - 各設定値の自動保存機能の検証（値変更後に設定画面を閉じて再度開いたときに維持されているか）。
  - 各入力値のバリデーション（ポート番号の範囲チェックなど）が正しく機能し、エラー時にフィードバックが表示されるか。
- [ ] **タッチストリップの操作性検証**
  - インタラクティブなタッチ要素が最低 35x35 px 以上のサイズを確保しており、タッチ操作が正常に反応するか。

### フェーズ2：掲載用メディア・ドキュメント作成

- [ ] **掲載用アセットの用意**
  - [ ] **サムネイル画像**: 1920×960pxのPNG画像を1枚作成する。
  - [ ] **ギャラリー用アセット**: 1920x960pxのPNG画像、または1920×1080pxのMP4動画を計3点以上作成する（Gフォース、タイヤ温度、速度計、サスペンションの実際の動作画面など）。
  - [ ] **プラグインのアイコン画像**: Marketplace表示用のアイコン（PNG）。
  - [ ] **デモンストレーションビデオ（必須）**: 外部ゲーム（Forza Horizon）との連携動作を示す実演動画（1920x1080 px、MP4形式、50MB以下）およびそのサムネイル画像（1920x960 px、PNG/JPEG）。
- [ ] **掲載文言の最終確認**
  - `docs/marketplace-listing.md` に記載されている製品説明（英語・日本語）を見直し、文字数やキーワードが適切かを確認する。**※Marketplaceの申請およびアセット内テキストは英語表記が必須です。**
- [ ] **追加リンクの整理**
  - GitHubのREADME.mdやリポジトリへのリンク、セットアップガイド、サポートページのURLを決定する。

### フェーズ3：リリースビルドと検証

- [ ] **リンターの適用**
  - `pnpm lint:fix` を実行し、コードと設定ファイルの書式を最適化する。
- [ ] **構成のバリデーション**
  - `pnpm streamdeck:validate` を実行し、`manifest.json` の構成に問題がないか確認する。
- [ ] **配布用パッケージの生成**
  - `@elgato/cli` または Elgato Distribution tool を用いて、配布パッケージ（`.streamDeckPlugin`）をエクスポートする。
- [ ] **実機インストールテスト**
  - 生成された `.streamDeckPlugin` を実際にインストールし、問題なく動作することを確認する。

### フェーズ4：Maker Consoleでの申請と審査対応

- [ ] **Makerアカウントの作成とログイン**
  - [Maker Console](https://maker.elgato.com) にてMakerとして登録する。
- [ ] **新規製品の登録**
  - 「Create product」を選択し、Stream Deck Pluginとして登録を開始する。
- [ ] **必要情報のアップロードと入力**
  - 配布用パッケージファイルのアップロード。
  - フェーズ2で作成した製品説明文（英語・日本語）、各種アセット（サムネイル、ギャラリー画像、アイコン、デモビデオ）、追加リンクの設定。
  - 初回リリースノートの記述。
- [ ] **レビュー申請とフィードバック対応**
  - 審査チームからの指摘事項があれば修正し、再提出する。
  - 承認後、無料公開される。
