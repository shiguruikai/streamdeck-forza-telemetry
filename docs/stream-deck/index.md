# Stream Deck Plugin Development Knowledge Base

This is a collection of knowledge documents for developing Stream Deck plugins, curated from the official Elgato Maker documentation.

> **注記**: このディレクトリは公式ドキュメントの機械的な転記であり、欠落がある（例: [plugin-guidelines.md](distribution/plugin-guidelines.md) では Do / Don't の区別が失われている）。判断の根拠にするときは、各ページの原文（docs.elgato.com）を確認すること。

## Subcategories

* [WebSocket API References](api/index.md) - WebSocket API specifications for communicating between the plugin, Property Inspector, and Stream Deck application.
* [Stream Deck CLI Reference](cli/index.md) - Stream Deck command line interface commands for creating, debugging, validating, and packaging plugins.
* [Distribution & Marketplace Submission Guide](distribution/index.md) - Guidelines, monetization setup, review process, and submission workflow for publishing plugins on Elgato Marketplace.
* [Stream Deck SDK & Core Concepts](sdk/index.md) - Core guides and references for the Stream Deck SDK, actions, dials, keys, and lifecycle events.
* [Property Inspector UI Components](sdpi-components/index.md) - Guides and UI elements of the SDPI Components library to build rich Property Inspectors easily.
