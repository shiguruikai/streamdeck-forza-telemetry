# Forza Telemetry for Stream Deck +

Forza Horizon および Forza Motorsport シリーズから送信されるリアルタイムのテレメトリデータを、Stream Deck + の液晶キーおよびダイヤル（タッチディスプレイ）に表示するプラグインです。

## 機能

- **速度計（Speed Meter）**
  - **概要**: 現在の車速、ギアポジション、RPM（エンジン回転数）を表示します。
  - **設定オプション**:
    - **表示レイアウト**: Full（速度・ギア・RPM）、速度のみ、ギアのみ、RPMのみ
    - **速度単位**: KM/H、MPH
- **レース情報（Race Info）**
  - **概要**: 現在のラップタイム、ベストラップ、現在の順位や周回数を表示します。
  - **設定オプション**:
    - **表示レイアウト**: Lap Time（現在のタイムとベストタイム）、Race Time（レース時間と順位/周回数）、Race Time Only、Current Lap Time Only、Best Lap Time Only、Lap Number Only、Position Only
- **タイヤ温度（Tire Temperature）**
  - **概要**: 4輪のタイヤ温度状況をカラーゲージでグラフィカルに表示します。
  - **設定オプション**:
    - **表示位置**: 全輪、左前（FL）、右前（FR）、左後（RL）、右後（RR）
    - **温度単位**: Celsius（℃）、Fahrenheit（℉）
- **サスペンション移動量（Suspension Travel）**
  - **概要**: サスペンションのストローク量をリアルタイムでメーター表示します。
  - **設定オプション**:
    - **表示位置**: 全輪、左前（FL）、右前（FR）、左後（RL）、右後（RR）
    - **表示モード**: Percentage（%）、Raw Value（0.0〜1.0）
- **Gフォースメーター（G-Force Meter）**
  - **概要**: 車両にかかる前後左右の加速度（G）をリアルタイムに視覚化します。
  - **設定オプション**:
    - **ピークGの表示**: オン、オフ
    - **表示スケール**: 1.0G、2.0G、3.0G
- **コンパス（Compass）**
  - **概要**: 車両の進行方位角（0〜359°）およびコンパス盤をリアルタイムに表示します。
  - **設定オプション**:
    - **Dial表示モード**: Arch（上半分拡大表示）、Circle（全円表示）
- **エンジン出力（Power & Torque）**
  - **概要**: 車両のリアルタイムなエンジン出力（馬力など）およびトルク数値を表示します。
  - **設定オプション**:
    - **表示モード**: Both（出力とトルクの両方を表示）、Power Only（出力のみ表示）、Torque Only（トルクのみ表示）
    - **単位プリセット**: PS & N·m（現代日欧規格）、PS & kgf·m（日本伝統規格）、HP & ft·lb（英米規格）、kW & N·m（SI/EV規格）

## 使い方

### 1. ゲーム側の設定

Forza Horizon または Forza Motorsport のゲーム内設定メニューから、テレメトリのUDP送信を有効にします。

1. ゲーム内の設定メニューから **HUDとゲームプレイ（HUD & Gameplay）** を開きます。
2. 以下の項目を設定します。
   - **データ出力**: オン
   - **データ出力 IP アドレス**: `127.0.0.1`
   - **データ出力 IP ポート**: `24000`（任意の値）
   - **データ出力パケットフォーマット（Forza Motorsportのみ）**: `Car Dash`

### 2. プラグイン側の設定

1. Stream Deck アプリ上で、本プラグインのアクションを液晶キーまたはダイヤルに配置します。
2. 設定画面の **Global** タブから以下を設定します。
   - **IP Address**: ゲーム側の設定と一致するIPアドレス（デフォルト: `127.0.0.1`）
   - **Port**: ゲーム側の設定と一致するポート（デフォルト: `24000`）
   - **Font**: 表示に使用するフォント（等幅の`BIZ UDGothic`などを推奨）
   - **Frame Rate (FPS)**: 描画レート（10、15、20、25、30 FPS）
3. **Action** タブから、表示単位やレイアウトなど個別のアクション設定を行います。

> [!TIP]
> UDPデータは1つのアプリしか受信できません。
> その制限を回避し、他のアプリでもUDPデータを受信したい場合は、[SimHub](https://www.simhubdash.com/) などのポートフォワーディング機能を活用してください。

## 動作要件

- **ハードウェア**: Stream Deck + など
- **ソフトウェア**: Stream Deck アプリケーション v7.1 以降
- **OS**: Windows 10/11 または macOS 12 以降
- **対応ゲーム**:
  - Forza Horizon 4 / 5 / 6
  - Forza Motorsport 7 / 2023
    - ※Dash形式のみサポート（Sled形式は非サポート）

詳細は [AGENTS.md](AGENTS.md) を参照してください。

### 前提条件

- Node.js v24
- pnpm

### はじめる

```bash
# 依存関係のインストール
pnpm ci

# 開発モードを開始（ファイルの変更を監視し、自動的にプラグインを再起動する）
pnpm watch
```
